# Contributing to `understand`

Use real response failures to guide changes: include the prompt, the response, and what made it difficult to understand or act on.

Keep changes focused:

- Preserve agent autonomy, accuracy, safety, and requested detail.
- Add structure only when it helps the reader.
- Prefer a few flexible guardrails over rigid output templates.
- Keep `SKILL.md` concise and cross-compatible with Codex and Claude Code.
